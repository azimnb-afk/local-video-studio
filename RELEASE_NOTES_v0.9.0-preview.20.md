# Local Video Studio v0.9.0 Preview 20

Preview 20 keeps the public source snapshot and unsigned Apple Silicon download workflow compatible with Xcode's numeric application version rules.

Download the `LocalVideoStudio-0.9.0-preview.20-unsigned.zip` asset from the GitHub Release, expand it, and use Finder's **Open** command on first launch. This preview is unsigned/not notarized; no model weights are bundled.
