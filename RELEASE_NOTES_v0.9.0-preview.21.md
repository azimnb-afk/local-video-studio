# Local Video Studio v0.9.0 Preview 21

Preview 21 publishes a locally verified, unsigned Apple Silicon app zip alongside the clean public source snapshot.

## Download

Download `LocalVideoStudio-0.9.0-preview.21-unsigned.zip` from the GitHub Release and verify it with the accompanying `.sha256` file. Expand the zip, move `Local Video Studio.app` to Applications, and use Finder's **Open** command on first launch.

The app was built from this public source snapshot with Xcode on Apple Silicon. It is unsigned/not notarized, so macOS may show an additional confirmation. No model weights are bundled; configure compatible local models explicitly in Preferences.

Developer ID signing and notarization remain a separate distribution step.
