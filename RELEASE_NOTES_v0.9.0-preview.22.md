# Local Video Studio v0.9.0 Preview 22

Preview 22 is the recommended public download. It contains the latest model-readiness and local model display fixes and an arm64 app bundle whose internal build number is 22.

Download `LocalVideoStudio-0.9.0-preview.22-unsigned.zip` from the GitHub Release and verify the accompanying `.sha256` file. Expand the zip, move `Local Video Studio.app` to Applications, and use Finder's **Open** command on first launch.

This preview is unsigned/not notarized. No model weights are bundled; configure compatible local models explicitly in Preferences.
